# Il Mio Registro — V12.2

Registro finanziario personale con entrate, uscite, scadenze, pagamenti programmati, rate, contabilità, saldi, carte, contanti, linee telefoniche, crediti account, gift card, pianificazione e backup locale.

## PWA
- Una sola icona ufficiale: `icon.png`
- Manifest aggiornato
- Service worker con cache versionata, aggiornamento automatico, pulizia della cache precedente e migrazione dei dati delle versioni precedenti

## Privacy
I dati dell'app vengono salvati localmente nel browser tramite `localStorage`. Non vengono richiesti numero completo della carta, CVV, PIN o password.

Il listino tabaccheria incluso è uno snapshot parziale e va considerato aggiornabile.
